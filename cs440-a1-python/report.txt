# Why is the agent's first move east rather than north in Figure 1(a) of
# the handout, given that it does not yet know which cells
# are blocked?  Then: why are Manhattan
# distances consistent when the agent may move only in the four compass
# directions and every move costs one?
The agent's first move is east in Figure 1(a) because the East cell has the lowest Manhattan distance compared
to the North and West cell to the goal. If the agent only moves in the four cardinal distances with cost of 1,
the Manhattan Distance is the lowest cost way to reach any cell under the freespace assumption. Moving to any
other cell would increase the distance traveled, which satisfies the inequality h(s) <= c(s, s’) + h(s’).

# Why must the agent either reach the target or discover that it cannot, in
# finite time?  Give the argument, and the reason the number of moves is bounded
# above by the number of unblocked cells squared.
Agent will explore every cell that is unblocked from every cell that has a path to it that is not blocked.
Each path that a cell explores has a potential length of N - 1. This means that we have N * (N - 1), or 
O(N^2) time to complete.

# Prove the w-times-optimal bound for a consistent base h without reopening.

With a consistent h, g(s) <= wg*(s) for selected states on an optimal path. So a frontier node has fw <= wC*, and the goal cost is bounded by wC* without reopening. For a game, if the sweep confirms useful savings, we can choose w=1.5 since larger weights can increase expansions.
